How this project uses it
------------------------
Only for the **ASCII part of the anti-fake code** on the watermark's
bottom-right brand block (14 digits/letters, monospaced so the columns
line up). The face contains **no CJK glyphs** (its `cmap` has zero
segments covering U+4E00–U+9FFF), so the Chinese label "防伪" is still
drawn with the system font — see `WatermarkRenderer.BrandSeg`.

Verified on 2026-09-27 with `watermark-camera/verify/font_info.js`.
